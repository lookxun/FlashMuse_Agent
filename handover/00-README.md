  ✅ 用 CDP：`page.context().newCDPSession(page)` → `Network.emulateNetworkConditions({ latency: 3000, ... })`。
  ⛔⛔ **必须在 `finally` 里恢复 `latency: 0`** —— 2026-07-31 我中途报错、恢复那行没跑到，

  验"模型/分辨率走对没有"读节点右上角标签而不是看图。完整姿势见 `07` **第十一·B 节**。
